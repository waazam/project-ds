development session/milestone and broken down by category (story beats,
level design, additions, subtractions, bug fixes, audio fixes, and so on —
only the categories with actual content appear in a given entry).

This is a narrative supplement to `git log`, not a replacement for it: each
entry links back to the commit(s) it summarizes so you can always go read
the real diff. When you land a new batch of work worth debriefing, add a new
file here named `YYYY-MM-DD-slug.md` (append `a`/`b`/`c` to the date if more
than one entry lands the same day) and list it below.
